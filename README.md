# 💸 BrokeOrNot?

> *"Track your budget. Get roasted. Regret your spending decisions in real time."*

**BrokeOrNot** is a student expense manager built using pure HTML, CSS, and JavaScript that combines budgeting with humour, animations, and an aggressive financial roasting system.

Unlike normal expense trackers, this app doesn't just show your spending — it actively judges you for it.

---

# ✨ Main Highlight — The Roasting System

The core speciality of **BrokeOrNot** is its dynamic roast & alert system.

As users spend more of their monthly budget, the app unlocks escalating warning levels:

| Remaining Budget | Alert Level             |
| ---------------- | ----------------------- |
| ≤ 80%            | 👀 Heads Up             |
| ≤ 50%            | 😬 Warning              |
| ≤ 40%            | 😰 Alarming             |
| ≤ 30%            | 🚨 Critical             |
| ≤ 20%            | 💀 Financially Deceased |

When users continue spending during dangerous levels, the app triggers:

* 🔥 Savage roast banners
* 🚨 Pulsing red screen alerts
* ⚡ Full-screen flash effects
* 💀 Animated critical popups
* 🎭 Rotating sarcastic messages

The system becomes more intense as the wallet approaches zero.
